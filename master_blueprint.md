# BUILD App - Master Architecture & Deployment Blueprint

## 1. Project Overview
BUILD is a bitemporal engineering career platform and NCrF compliance tracking system designed for Indian universities[cite: 4]. It features a student-facing PWA frontend, an intelligent dynamic pacing engine, and a verified "Proof of Work" repository engine[cite: 4].

## 2. Tech Stack & Infrastructure (Zoho Catalyst)
- **Frontend Hosting:** Zoho Catalyst Slate (Static Web Assets)[cite: 4]
- **Backend Services:** Zoho Catalyst AppSail (Node.js / Express Runtime)[cite: 4]
- **Database:** Zoho Catalyst Data Store (NoSQL / Relational Tables)[cite: 4]
- **CI/CD Pipeline:** Zoho Catalyst Pipelines integrated directly with GitHub Actions[cite: 4].

## 3. Core User Flow & Modules
- **Module 1: Onboarding & Track Selection** (3-Month Explorer vs. Software Engineer Track)[cite: 4].
- **Module 2: Dynamic Timetable & Anti-Burnout Engine** (Day-by-day college hour calculations determining daily career study limits)[cite: 4].
- **Module 3: Roadmap Preview & Customization** (Milestone visualization with real-time pace adjustments)[cite: 4].
- **Module 4: Daily Dashboard & Task Execution** (Theory modules, practice arena, and mandatory self-care logs)[cite: 4].
